# 带上她的眼睛

Godot 4.7.2 完整互动阅读游戏的网页发行工程。

公开体验入口：<https://jzjz225.github.io/eyes-of-dusk/>

## 内容

一、前序；二、草原；三、落日六号；四、透明地球。保留原游戏的分格漫画、六幕互动、视频、音乐、QTE、字幕和 2K 地心结尾。

本仓库中的 `game/` 是正式桌面工程的网页适配副本，入口场景是 `game/scenes/main.tscn`。网页入口 `dist/index.html` 由 Godot 正式导出再包装生成，不使用旧 HTML 原型替代游戏。

原有图片、视频和音乐没有额外降低分辨率或重新编码。资源包按字节拆分为 32 MiB 分块，并逐块 SHA-256 校验；这是传输方式调整。已无引用的旧试做素材不进入发行包。中文字体以当前使用字形封装，并提供完整 CJK 字体供编辑选择，保留保存的文本框排版与场景布局。画布固定为 2560×1440，再按窗口等比例显示。

首次启动需要加载约 880 MB 完整资源。页面显示实际进度，浏览器在存储空间允许时缓存素材。进入后使用游戏内操作；Esc 打开设置，主菜单设置可选择四章。推荐电脑端现代 Chrome、Edge 或 Firefox。

## 自动构建与部署

推送到 `main` 自动运行 `.github/workflows/pages.yml`：凭据扫描 → 官方 Godot 与匹配 Web 模板 → 原素材导入 → 网页导出 → 无损分块校验 → GitHub Pages 部署。

工作流只使用 GitHub 的自动令牌，不需要把个人 Token 写入仓库。官方依赖固定到版本或提交，构建发现疑似凭据时停止。

本地运行：

```text
python tools/fetch_web_templates.py --output .web-templates
python tools/build_web.py --godot <Godot-4.7.2可执行文件>
python -m http.server 8120 --directory dist
```

`dist/`、导入缓存、引擎下载与日志均不提交到 Git。构建产物整体小于保守的 1,000,000,000 字节预算。每次资源更新使用新的内容指纹路径，避免新旧素材混用。

本地原生工程仍是内容制作来源；网页适配集中在嵌入字体、浏览器存档、传输缓存和固定画幅，不覆盖桌面版。
