# 带上她的眼睛

Godot 4.7.2 完整互动阅读游戏的网页发行工程。

公开体验入口：<https://liziyan888.github.io/eyes-of-dusk/>

## 内容

一、前序；二、草原；三、落日六号；四、透明地球。保留原游戏的分格漫画、六幕互动、视频、音乐、QTE、字幕和 2K 地心结尾。

本仓库中的 `game/` 是正式桌面工程的网页适配副本，入口场景是 `game/scenes/main.tscn`。网页入口 `dist/index.html` 由 Godot 正式导出再包装生成，不使用旧 HTML 原型替代游戏。

原有图片、视频和音乐没有额外降低分辨率或重新编码。资源包按字节拆分为 4 MiB 分块，并逐块 SHA-256 校验；这是传输方式调整。已无引用的旧试做素材不进入发行包。中文字体以当前使用字形封装，并提供完整 CJK 字体供编辑选择，保留保存的文本框排版与场景布局。画布固定为 2560×1440，再按窗口等比例显示。

首次启动在开始游戏前加载全部资源。约 880 MB 原始资源包经逐块无损传输压缩后，本版实际传输约 859 MB（不含引擎）；解压重组后的包与原导出逐字节一致。页面显示实际准备进度、接收速度和预计剩余时间，在 3/6/8 路下载之间比较吞吐量；慢连接和重试时降低并发。中断的分块通过 HTTP Range 从已收到的位置续传，服务器不支持时安全重下该分块。引擎与素材同时下载，完整校验后再开放原生开始菜单。

浏览器在存储空间允许时逐块保存解压后的素材，刷新或重试会复用已校验的分块；缓存键沿用旧版原始内容指纹，压缩传输不会强制丢弃旧缓存。读取缓存最多三块并行，不无界占用内存；旧版 32 MiB 缓存中仍匹配的内容也会复用。缓存关闭或空间不足时仍可正常游玩。进入后使用游戏内操作；Esc 打开设置，主菜单设置可选择四章。推荐电脑端现代 Chrome、Edge 或 Firefox（需要内置 gzip 解压流支持）。

互动粒子已使用 680 实例的显卡批量绘制，保留细碎密度、4.8 秒慢速直线扩散；漫画与大互动点白圈持续呼吸，悬停额外提亮。不会降低原画、视频或音乐质量来加快加载。首次网络速度仍取决于玩家到 GitHub Pages 的链路，不以本机缓存速度代替首开测速结果。

加载封面使用游戏原画、相同 16:9 画幅，以及已保存的标题文字、字号和开始按钮位置。打开链接即开始准备资源，完整素材准备好后显示原游戏的开始按钮。

## 自动构建与部署

推送到 `main` 自动运行 `.github/workflows/pages.yml`：凭据扫描 → 官方 Godot 与匹配 Web 模板 → 原素材导入 → 网页导出 → 无损分块校验 → GitHub Pages 部署。

工作流只使用 GitHub 的自动令牌，不需要把个人 Token 写入仓库。官方依赖固定到版本或提交，构建发现疑似凭据时停止。

本地运行：

```text
python tools/fetch_web_templates.py --output .web-templates
python tools/build_web.py --godot <Godot-4.7.2可执行文件>
python -m http.server 8120 --directory dist
```

`dist/`、导入缓存、引擎下载与日志均不提交到 Git。构建产物整体小于保守的 1,000,000,000 字节预算。每次资源更新使用新的内容指纹路径，避免新旧素材混用。

本地原生工程仍是内容制作来源；网页适配集中在嵌入字体、浏览器存档、传输缓存和固定画幅，不覆盖桌面版。
